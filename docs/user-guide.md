# 订单管理 · 使用手册

> 给日常使用看的简化版。设计细节见 `order-tracker-system-design.md`。

## 这是什么

一个 macOS 小工具，帮你管三件事：

1. **代购订单**：客户付款 → 你下单 → 发货 → 完结，自动算每单赚多少
2. **团（批次）**：同一网站的一批订单归成一团，信用卡结账后一键把实付金额分摊到每单，三本账自动对平
3. **囤货**：自己囤的货，挂单、转售出，库存占用一目了然

外加统计页（月度收益、团对比、退款/丢失账本）和设置页（网站管理、导出 CSV、备份）。

## 安装

从 GitHub Releases 下载 dmg，拖进「应用程序」。

**首次打开提示"已损坏"**：这是因为 app 无签名，macOS Gatekeeper 拦截。打开「终端」执行一次：

```bash
xattr -cr /Applications/ShoppingList.app
```

之后即可正常双击打开（每次升级覆盖安装后如再报"已损坏"，重跑一次该命令）。

## 五分钟上手

1. **设置页 → 网站管理**：加几个常用网站（如 JAYD 澳洲站），选个颜色
2. **订单页 → 新建**：填买家微信、网站、商品、卖出价；有外币成本就填外币金额 + 汇率，系统自动算出人民币成本
3. 货到了点**标记发货**（填快递单号和邮费）→ 客户确认收货后点**完结**
4. 统计页看本月收益

## 三个日常流程

### 流程一：普通代购单

```
客户付款 → 你录单（待发货）→ 网站下单 → 收货发货（已发货）→ 客户收货（完结）
```

- 录单时**成本可以后补**，但转「已发货」前必须填，否则系统不让转
- 收益 = 卖出价 − 成本 − 邮费 ± 调整项，发货那个月计入月度统计

### 流程二：开团 + 结算分摊

1. **团页 → 新建团**：选网站和币种（一个团只能用一种外币）
2. 从团详情「**+ 加订单**」录单（网站和币种自动锁定）；已有散单也可以挂进团（网站、币种必须一致）
3. 信用卡账单出来后，在团的结算区填**实付总额 + 实际汇率**
4. 点「**结算分摊**」：系统按各单外币成本比例，把实付总金额摊到每单（最大余数法补尾差，分毫不差）

分摊前，每单成本是「预估」；分摊后变成「实际」，订单、月度、团三本账**构造性对平**。改了某单成本后团会变「待重新分摊」（橙色），再点一次分摊即可。

**团的四种结算状态**：

| 状态 | 含义 | 你该做什么 |
|---|---|---|
| 预估 | 还没填实际汇率 | 等账单，不急 |
| 待分摊 | 汇率填了还没分摊 | 点「结算分摊」 |
| 已分摊 | 数字是实际的 | 不用管 |
| 待重新分摊 | 分摊后又改了东西 | 再点一次「结算分摊」 |

**手改过的成本永远最高优先级**：分摊不会动你手动锁定的单。

### 流程三：囤货

1. 订单页新建时类型选「囤货」→ 出现在**库存页**（在库）
2. 想卖就点「挂单」（挂单中），不想卖点「下架」
3. 有人要了 → 点「**转售出**」，补买家微信和卖出价 → 自动变成普通代购单，走流程一
4. 自己用掉了 → 点「自用」（不计盈亏）

**重复商品一键复制**：同一商品买了好几件，不用重复录入——订单页/库存页点行尾「**复制**」，填份数确认，自动生成 N 条新的在库囤货单（新订单号）。商品、成本、汇率、成本调整都会带过来；买家信息、卖出价、运费、快递单号会清空。客户单也能复制，复制后同样变成囤货单。注意：还没补成本的单不能复制。

## 状态机详解

### 代购单（customer）

| 状态 | 颜色 | 含义 | 能去哪 |
|---|---|---|---|
| 待发货 | 蓝 | 已付款未发货 | 已发货 / 退款 / 丢失 |
| 已发货 | 浅绿 | 快递在路上 | 完结 / 退款 / 丢失 / 退回待发货 |
| 完结 | 无色 | 交易结束 | 可退回已发货（改错用） |
| 退款 | 深红 | 全额退款，收益记 0 | 可回退（纠错） |
| 丢失 | 深红 | 件丢了，收益记负成本 | 可回退（纠错） |

- **回退 = 时光倒流**：退回「待发货」会清空发货时间（月度统计跟着改），快递单号保留
- 退款/丢失按点下按钮的那个月，进统计页的**异常账本**
- 完结纯手动；邮费没填时点完结会弹确认（按 0 邮费算）

### 囤货单（stock）

| 状态 | 颜色 | 含义 | 能去哪 |
|---|---|---|---|
| 在库 | 紫 | 囤着 | 挂单 / 自用 / 丢失 / 转售出 |
| 挂单中 | 浅紫 | 挂出去卖了 | 下架 / 自用 / 丢失 / 转售出 |
| 自用 | 无色 | 自己用了，无盈亏 | 可回退 / 也可直接转售出 |
| 丢失 | 深红 | 货没了，计负成本 | 找回先回退「在库」 |

## 常见问题

**成本填错了怎么办？**
直接编辑订单改。手改后的成本会被「锁定」（显示"已手动修改"），分摊不动它；想让分摊重新管这单，去团里重新分摊。

**汇率哪里来？**
在**设置页 → 汇率维护**集中管：三个币种（AUD/USD/HKD）可手填，或点「全部刷新」联网查一次。录单选了币种就自动带出这里的汇率（没带出来就手填，或点「获取实时汇率」现场查）。这只是预估；真正算账用团的**实际结算汇率**（信用卡账单上的），永远手填。

**月度收益按什么算？**
按**发货月份**归属。没发货的单能看到预计收益，但不进月度统计。丢失的亏损按标记丢失的月份扣。

**有单没填成本会怎样？**
收益显示「—」，统计页会橙色提示「N 单未补成本，统计不完整」——绝不会静默当 0。

**数据在哪？安全吗？**
存在本机 `~/Library/Application Support/com.cloudiiink.shoppinglist/tracker.db`（v1.0.3 起应用改名 ShoppingList，目录随 identifier 变更）。设置页点「立即备份」生成快照（保留最新 2 份）；超过 7 天没备份会提醒你。备份只防误操作，**建议定期把备份文件拷到 iCloud 或移动硬盘**。

**从 order-tracker 升级到 ShoppingList（数据迁移）**
新版 identifier 变了，首次打开会看到空库。退出两个 app 后把旧数据拷过去即可：

```bash
mkdir -p ~/Library/Application\ Support/com.cloudiiink.shoppinglist
cp ~/Library/Application\ Support/com.cloudiiink.ordertracker/tracker.db* ~/Library/Application\ Support/com.cloudiiink.shoppinglist/
```

**换电脑/重装怎么恢复？**
退出 app → 把备份文件改名为 `tracker.db` 放进上面那个目录 → 重新打开。

**能导出吗？**
设置页 → 导出 CSV：全部订单（含团名列），金额自动换成「元」，可直接用 Excel/Numbers 打开。
